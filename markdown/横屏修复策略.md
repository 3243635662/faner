# 十、比较稳的判断方案

Flutter 本身并不知道：

> “这到底是一台手机还是一台平板”

所以可以把设备尺寸分类抽成一个专门工具。

例如：

```dart
enum WindowClass {
  compact,
  medium,
  expanded,
}
```

然后：

```text
< 600
→ compact

600 ~ 839
→ medium

>= 840
→ expanded
```

但是：

**不要直接拿 `expanded` = 平板。**

你更应该结合：

```text
最短边 shortestSide
```

例如：

```dart
final shortestSide = MediaQuery.sizeOf(context).shortestSide;
final isTablet = shortestSide >= 600;
```

这样：

### 手机竖屏

```text
390 × 850

shortestSide = 390
→ 手机
```

### 手机横屏

```text
850 × 390

shortestSide = 390
→ 仍然是手机
```

### 平板横屏

```text
1280 × 800

shortestSide = 800
→ 平板
```

这才是你当前 Bug 最应该采用的判断。

# 十一、于是 `_onTapEntry()` 应该变成这样的思想

```dart

```

```text

+
“是否应该进入双栏”
```


| 平板 | 竖屏 | 打开媒体/单栏    |
| 平板 | 横屏 | **右侧预览 ✅** |

这正好符合你的需求。

一、修复手机横屏无法打开媒体的问题

当前 LocalBrowserPage / RemoteBrowserPage 使用：

```dart

```

```dart
  select(entry);

```
